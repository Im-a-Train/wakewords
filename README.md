# wakewords

Eigene Wake Words für den Home Assistant Voice PE (microWakeWord).

- `hey_hene*.tflite/.json` – bisherige Modelle
- `voice-pe-hey-hena.yaml` – ESPHome-Konfiguration des Voice PE (offizielle Firmware + «Hey Henä»)
- `my-wakeword.yaml` – alte, vollständig kopierte Firmware-Konfiguration
- [`training/`](training/README.md) – lokale Trainings-Pipeline in Docker (AMD ROCm oder CPU) für «Hey Henä»
